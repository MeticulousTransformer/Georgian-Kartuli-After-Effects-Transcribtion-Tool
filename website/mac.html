Install on Mac

A native app for Apple Silicon and Intel. No Terminal setup.

Check the release notes for signing status. Earlier preview builds, including dcaf15d, are not Apple notarized and need the opening approval described below.

  1. Download the macOS DMG from the download page.
  2. Open the disk image and drag CapForge to Applications. Open CapForge from Applications.
  3. Save your project and close After Effects.
  4. Select Allow unsigned Adobe extensions for this account for this preview. This affects all unsigned Adobe panels for your account.
  5. Click Install CapForge. Keep your internet connection available while setup prepares audio and transcription support.
  6. Open After Effects and choose Window → Extensions → CapForge. Your version may call the menu Extensions (Legacy).

Your first captions

Open CapForge’s Setup tab and start the service if it is not connected. Add one AI provider key, or try the built-in demo without a paid account. In Source, choose a short clip and language. Transcribe, review your words, choose a design, then Generate captions.

If macOS cannot verify the developer

Only proceed if you trust the official download. After trying to open CapForge, use System Settings → Privacy & Security → Open Anyway for this app. Read Apple’s instructions. Keep Gatekeeper enabled; a managed work computer may require your administrator’s approval.

Updating and repairing

In the AE panel, choose Setup → Check for updates → Update. The correct Mac package is selected automatically. Save and close AE, complete setup, then reopen AE. To replace the app in Applications manually, download the latest DMG and drag the new app there.

If setup fails, the native window shows the error and a Logs button. Fix the reported issue and retry. Your keys and exported transcripts are preserved.

Where your work lives

The service and exported files live in ~/Library/Application Support/CapForge. Older owned installations may keep their previous folder. Keep that folder in place. Export JSON after editing a transcript and save your AE project normally.

More help

Read the full guide on GitHub or report an issue. Include your OS, AE version, CapForge build and the error message. Never include API keys.
